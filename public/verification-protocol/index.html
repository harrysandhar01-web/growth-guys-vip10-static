VIP10 Verification Protocol v1.0

Names for the records the desk actually keeps.

This protocol defines the public labels used for cart-only VIP10 observations. It does not describe an order, payment approval, fulfillment, universal eligibility, or medical use.

01

Accepted

A retained cart-only observation shows VIP10 visibly applied, with product context, cart subtotal, observed discount, and a retained screenshot. This establishes only the displayed cart response.

02

Manual review required

A public cart observation exists after an attempted VIP10 application, but the accepted-result evidence threshold is incomplete. It is not an accepted result or a rejection claim.

03

Stock unavailable

No discovered public listing was visibly eligible for the controlled guest-cart check. This is an availability record, not a conclusion about VIP10.

04

Checkout blocked

The public storefront did not expose enough cart-eligible context to complete the controlled observation. It is not a code outcome.

05

Documented cart result

A cart-only result retained with the visible outcome, event time, product context, and screenshot evidence. The label describes what the evidence proves, not how the browser observation or publication was produced.

06

Documented manual observation

A cart-only observation personally performed or supplied by the user and retained under the same public evidence rules.
