# Homepage heading standard

The homepage H1 is intended to remain stable: Growth Guys Promo Code VIP10 — 10% Off, Verified Daily at Checkout. Daily means the regular checkout-check schedule; the dated latest successful observation remains separate and must not be advanced if a check fails. Do not imply every item or basket qualifies. Supporting page headings and archive records remain distinct. Automated projection must preserve this homepage wording for checkout records; if checkout evidence is unavailable, accurately label the actual evidence scope.
